# conformance/core

The Floorspec Core conformance suites, one directory per draft: `0.1/` and `0.2/` (as published,
unchanged) and `0.3/` (the current spec text, which also holds every 0.2 test re-targeted to 0.3).
See [`../README.md`](../README.md) for the layout of a test and how the suites are checked.
