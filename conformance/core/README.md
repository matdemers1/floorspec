# conformance/core

The Floorspec Core conformance suites, one directory per draft: `0.1/`, `0.2/` and `0.3/` (as
published, unchanged) and `0.4/` (the current spec text, which also holds every 0.3 test
re-targeted to 0.4). See [`../README.md`](../README.md) for the layout of a test and how the suites
are checked.
